# ИИ-страница в Instagram: стратегия, производство, контент-план

Статус 08.10.2026: черновик стратегии, ничего не сгенерировано и не опубликовано. Ждём «да» и ответы на вопросы из §13.
Режим ведения (предложение): автопилот через Meta (Instagram Graph API) с ежедневным отчётом — правила и подключение в `AUTOPILOT.md`.
Визуальная версия с графиками: артефакт «ИИ на смене — план запуска» (ссылка в чате).

Идея: Instagram-страница про эффективность ИИ-моделей, в первую очередь Claude Code. Контент-план, сценарии, моушен-графику, обложки, озвучку и аналитику делает ИИ (Claude Code). Человек одобряет и нажимает «опубликовать». Цель: охват → подписчики → лид-магнит → платный гайд → курс.

## 1. Разбор референса (смотрел покадрово, 62 кадра + спектр звука)

Ролик: `@nikitadik.ai` («Никита • AI без кода | автоматизация»), 07.10.2026, на момент разбора 44 лайка и 4 комментария.
Как достал: прямой доступ Instagram режет (429), сервис Everygen без подписки не качает. Поэтому написал свой помощник `tools/reel_grab.js`: headless Chromium открывает embed-плеер и забирает mp4. Дальше ffmpeg режет кадры.

**Технически:** 9:16, 720×1280, 30 fps, 31 с, без единой склейки. Это не видео, а **анимированный HTML-интерфейс** (дашборд-симуляция): так выглядит код на HTML/CSS/JS с анимацией, записанный в видео. Такое Claude Code умеет делать сам, и бесплатно.

**Сюжет: одна идея, 4 главы по ~7 с, прогресс-бар сверху как в сторис (01/04 … 04/04):**

| Время | Глава | Что происходит на экране | Итог |
|---|---|---|---|
| 0–7 с | ДЖУН | 6 запросов-точек летят светящимися импульсами в Opus 5.5, усилие MAX | $1.00 за задачу |
| 7–14 с | МИДЛ | Простые запросы в Haiku, средние в Sonnet, сложные в Opus, усилие везде HIGH; 2 результата красные (ошибки всплыли позже) | $0.27 |
| 14–21 с | СЕНЬОР | Сначала Haiku, потом проверка; не прошло → выше. Счётчик повторов 4 | $0.14 |
| 21–31 с | МАРШРУТИЗАТОР | Роутер сам выбирает модель, усилие и глубину проверки по риску | $0.09 |
| 28–31 с | Финал | «Те же шесть задач. Разница в 11 раз» + столбчатая диаграмма Д/М/С/Р | петля |

**Дизайн:** тёмно-коричневый фон с сеткой, кремовый текст, оранжево-янтарные акценты, свечение. Жирный гротеск в заголовках, моноширинный шрифт в подписях. Карточки моделей, полоски «усилия», счётчики токенов и стоимости, квадратики результатов, растущий бар-чарт. Импульсы бегут по линиям, как по схеме платы.
**Звук:** по спектрограмме это музыкальная подложка с тиками/щелчками на переходах глав, голоса нет.
**Обложка** отдельная: 3D-стеклянный куб + крупный текст «Одна задача: доллар или девять центов · 4 уровня работы с моделями».
**Подпись:** весь сценарий текстом + 3 хештега, CTA нет.

**Что работает (берём себе):**
1. Одна мысль, одно сравнение, конкретные деньги. Цифра падает: $1.00 → $0.27 → $0.14 → $0.09.
2. Структура «уровни» (джун/мидл/сеньор) — люди примеряют на себя.
3. Прогресс-бар 01/04 держит досмотр: зритель видит, сколько осталось.
4. Финальный кадр — готовая инфографика, её сохраняют и пересылают.
5. Делается кодом, значит, шаблон можно переиспользовать сотни раз.

**Что слабо (наше преимущество):**
1. **Нет хука в первом кадре.** Ролик стартует с полупустого дашборда, хук только на обложке. В ленте Reels обложку не видно, первые 1,5 с решают всё.
2. **Мелкий текст.** Подписи 10–12 px на 720 — с телефона не читаются. Нижняя треть кадра пустая.
3. **Нет голоса и нет CTA.** Нет повода подписаться или написать в директ.
4. **Нет доказательства.** Цифры похожи на иллюстрацию, а не на реальный замер. Мы будем показывать реальные тесты.
5. Охват слабый (44 лайка) — маленький аккаунт без воронки. Формат хороший, упаковки нет.

## 2. Позиционирование

**Рабочее имя:** «ИИ на смене» (варианты ника: `@ii.na.smene`, `@agent.na.smene`, `@kod.bez.koda`). Не используем «Claude» и логотипы Anthropic в нике и аватарке: это чужой товарный знак.

**Концепция:** публичный эксперимент. «Эту страницу ведёт ИИ-агент. Я только нажимаю “опубликовать”». Каждый ролик заканчивается плашкой-подписью: `Сделано Claude Code · 14 мин · $0.38`. Сам аккаунт становится кейсом: подписчик видит, что ИИ реально работает, а не слышит об этом.

**Аудитория (по приоритету):**
1. Предприниматели и фрилансеры без кода: хотят автоматизировать заявки, контент, таблицы.
2. Маркетологи/SMM: хотят делать контент быстрее.
3. Джуны и мидлы в IT: хотят работать с Claude Code эффективнее и дешевле.

**Обещание профиля (шапка):**
> ИИ ведёт этот блог сам · сравниваю модели на реальных задачах · Claude Code без кода
> ↓ гайд «Claude Code за 7 дней» — напиши ГАЙД в директ

**Тон:** спокойный, цифры вместо восторгов. Каждое утверждение = тест, замер или скрин. Никаких «ИИ заменит всех».

Единая сетка: крупный текст 2–3 строки + один 3D-объект или иконка модели. Делаем в HTML (бесплатно) или Nano Banana (2 кр). Сетка профиля — по 3 в ряд, цвета чередуются по столпам.

## 5. Дизайн-система «Смена» (своя, не копия референса)

- Фон графит `#0E0F12`, поверхность `#17181D`, бумага `#EEE8DD`.
- Акцент «сигнальный» — один на ролик. Цвета моделей фиксированы, чтобы зритель узнавал их без подписи: Claude — коралл, GPT — бирюза, Gemini — синий, open-source — фиолетовый.
- Шрифты с кириллицей: Unbounded (заголовки), Manrope (текст), JetBrains Mono (цифры, подписи, терминал).
- **Правило читаемости (ошибка референса):** на 1080×1920 подписи от 34 px, заголовки от 96 px, цифры-итоги от 180 px.
- **Безопасные зоны Reels:** верх 220 px и низ 420 px не занимать важным, справа 140 px под кнопки.
- Фирменные элементы: прогресс-бар глав, плашка «Сделано Claude Code · мин · $», моно-счётчики.

**Курс «Claude Code без кода» (черновик, 6 модулей):**
1. Модели и деньги: какую брать, как не переплачивать (роутинг, усилие, проверка).
2. Claude Code с нуля: установка, первый проект, CLAUDE.md.
3. Агенты и субагенты: делегирование задач.
4. MCP и коннекторы: Google Таблицы, Telegram, почта, CRM.
5. Skills и hooks: свой процесс один раз → навсегда.
