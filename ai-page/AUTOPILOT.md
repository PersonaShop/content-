# Автопилот страницы: правила, ежедневная смена, отчёт

Статус 08.10.2026: черновик. Включается, когда (1) Claude получил доступ к Instagram, (2) пользователь подтвердил границы из §1, (3) создана ежедневная Routine (§5).
Стратегия и контент-план: `STRATEGY.md`. Клиент Instagram API: `tools/ig.py`.

---

## 1. Границы автономии (предложение; ждёт подтверждения)

| Сам, без вопросов | Только после «да» пользователя |
|---|---|
| Публиковать Reels, карусели, сторис из контент-плана и шаблонов T1–T8, C1–C5 | Платная реклама и продвижение постов |
| Менять порядок и темы в плане по статистике | Расход сверх дневного лимита (§4) |
| Отвечать на обычные комментарии и вопросы по теме | Ответы на негатив, жалобы, споры, вопросы о деньгах и возвратах |
| Отвечать на «ГАЙД» в директ готовым гайдом | Писать первым чужим аккаунтам (коллабы, упоминания) |
| Тестировать 2 хука на одну тему, время публикации, длину | Менять ник, имя, аватар, шапку |
| Удалять свой пост, если в нём ошибка в цифрах (и сообщить в отчёте) | Цены, продажи, запуск гайда или курса |
| Генерации до лимита (§4) | Новые сервисы и подписки |

**Стоп-слово:** пользователь пишет «стоп» или «пауза» — публикации прекращаются до слова «продолжай». Отчёты продолжают приходить.

**Жёсткие правила контента:** только свои замеры или источник с датой; модель и версия в кадре; без чужих логотипов в роли своего бренда; без обещаний заработка; в каждом ролике плашка «Сделано Claude Code» (раскрытие, что это ИИ).

## 2. Ежедневная смена (запускается Routine утром)

| Шаг | Что | Инструмент |
|---|---|---|
| 1. Статистика | Охват, досмотр, сохранения, пересылки, подписки по постам за 48 ч; подписчики за сутки | `ig.py stats --days 2` |
| 2. Комментарии | Ответить на открытые по правилам §1, сложные отложить в отчёт | `ig.py comments`, `ig.py reply` |
| 3. Разбор | Что сработало и почему; 1–2 правки в план | `state/log.csv`, `STRATEGY.md` §8 |
| 4. Новости | Есть ли релиз или событие, которое стоит отыграть за 24 ч | веб-поиск |
| 5. Производство | Сегодняшний пост по плану: сценарий → реальный тест → HTML-сцена → рендер → голос → обложка | шаблоны, Chromium, ffmpeg, Fish Audio |
| 6. QA | Чек-лист `STRATEGY.md` §9; при сомнении пост не выходит, вопрос в отчёт | — |
| 7. Публикация | В лучшее время по статистике (стартово 19:00 по аудитории) | `ig.py reel / carousel / story` |
| 8. Отчёт | Файл `reports/ГГГГ-ММ-ДД.md` + короткая сводка пользователю | §3 |
| 9. Сохранить | Записать пост в `state/log.csv`, закоммитить и запушить | git |

Сессия эфемерная: всё, что нужно завтра, лежит в репо (`state/`, `reports/`). Видео и картинки в репо не кладём, они пересобираются из шаблонов.

## 5. Подключение (что сделать пользователю)

1. **Instagram — профессиональный аккаунт** (Business или Creator).
2. **Доступ Claude к Instagram** — один из двух путей:
   - коннектор Meta/Instagram на https://claude.ai/customize/connectors, затем новая сессия (коннекторы читаются при старте сессии); в этой сессии он не виден;
   - или токен Instagram Graph API в секретах среды (меню среды в заголовке сессии → Edit → Network secrets или переменные окружения): `IG_TOKEN`, `IG_USER_ID`, при входе через страницу Facebook ещё `IG_HOST=graph.facebook.com`. Нужные права: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights`, `instagram_business_manage_comments`, для директа `instagram_business_manage_messages`. Токен в чат не присылать.
   - Сеть уже пропускает `graph.facebook.com`, `graph.instagram.com`, `rupload.facebook.com` (проверено 08.10).
3. **Подтвердить границы §1 и лимиты §4.**
4. **Время отчёта и часовой пояс** — для Routine.
5. По желанию: Telegram-бот для отчётов, API-ключи моделей для реальных сравнений.

## 6. Что API Instagram не умеет (делаешь ты или обходимся)

- Музыка из библиотеки Instagram и трендовые звуки: не добавить через API. Кладём свою музыку без авторских прав прямо в видео.
- Метка «Создано с помощью ИИ» в API может отсутствовать: раскрываем ИИ в ролике и в подписи.
- Карусели: картинки принимаются только по публичной ссылке → нужен хостинг (например, публичная корзина Supabase). Видео грузится напрямую, хостинг не нужен.
- Директ: через API можно отвечать в течение 24 ч после сообщения человека; рассылки по базе нельзя.
- Лимит публикаций через API в сутки с большим запасом выше нашего темпа.
